Visão Geral do Sistema

O que é o ZIO Monitor de Sites?

Visão Geral

O ZIO Monitor de Sites é uma plataforma avançada de observabilidade e monitoramento contínuo em tempo real. Ele acompanha a saúde, disponibilidade (uptime), código de status HTTP e latência (tempo de resposta) de websites, portas de servidores, APIs e microsserviços.

O sistema opera via chamadas HTTP/cURL de alta velocidade e armazena registros históricos em banco de dados SQLite, permitindo análise contínua do desempenho e alerta imediato de indisponibilidade.

Glossário de Termos & Métricas

Latência (ms)

Métrica

Latência (medida em milissegundos - ms) é o tempo exato que uma requisição HTTP leva para sair do servidor de monitoramento, alcançar o servidor do site e retornar os cabeçalhos de resposta completos (Round-Trip Time).

• 0 ms a 150 ms: Latência excelente. O site está muito rápido e responsivo.
• 151 ms a 500 ms: Latência moderada/aceitável.
• > 500 ms (Latência Alta): Alerta de lentidão. Pode indicar sobrecarga de CPU/Memória no servidor de destino, problemas no banco de dados do site ou gargalos de rede ISP.

Status ONLINE (UP)

Status

Indica que o site monitorado respondeu com sucesso dentro do tempo limite (timeout de 10s), retornando um código de resposta HTTP válido na faixa de sucesso (2xx, como HTTP 200 OK). O card exibe o indicador verde pulsante.

Status OFFLINE (DOWN)

Status

Indica que o site monitorado está indisponível ou apresentando falhas graves. Ocorre quando o servidor retorna erros HTTP (ex: 500, 502, 503, 404, 403), ultrapassa o tempo limite de conexão (timeout > 5s/10s), falha na resolução de DNS ou recusa a conexão TCP. O card exibe indicador vermelho pulsante e pode emitir alerta sonoro.

Intervalo de Verificação (Check Interval)

Configuração

É a frequência com que o ZIO Monitor dispara testes automáticos de conectividade para cada site. Opções configuráveis: 5s, 10s, 30s, 1 minuto, 5 minutos e 10 minutos. Monitores com menor intervalo detectam quedas mais rapidamente.

Recursos & Funcionalidades do Sistema

Verificar Agora (Check Now)

Recurso

Para que serve: Dispara uma checagem de status e latência imediatamente sob demanda para o site selecionado, ignorando o temporizador do intervalo automático.

Como usar: Clique no botão de ícone de rotação [ ↻ ] no card do site ou dentro do modal de detalhes do domínio. O ícone girará durante a requisição e atualizará os dados na tela instantaneamente.

Silenciamento Individual de Alertas (Mute por Domínio)

Recurso

Para que serve: Permite desativar notificações áudio/sonoras para um site específico (ex: um site que entrou em manutenção programada), sem desativar os alertas dos outros monitores.

Como usar: Clique no ícone de sino [ 🔔 / 🔕 ] no card do monitor. Quando silenciado, um pequeno sino amarelo riscado será exibido junto ao nome do site e o sinal de alarme sonoro será ignorado caso o site caia.

Alertas Sonoros Globais

Recurso

Como funciona: Emitem um bip sonoro duplo sintetizado via Web Audio API nativa do navegador (sem arquivos externos mp3) no instante exato em que qualquer monitor transiciona de ONLINE para OFFLINE. O botão no cabeçalho permite alternar entre Alertas: Ativos e Alertas: Mutados.

Categorização Múltipla & Filtros (Tags)

Recurso

Para que serve: Agrupa seus monitores por tags personalizadas (ex: Produção, E-commerce, APIs, Clientes). Permite associar múltiplas categorias por site separando-as por vírgula.

Filtro: Use o menu suspenso de categorias no topo da lista para visualizar rapidamente apenas os monitores pertencentes àquela categoria.

Ordenação Inteligente de Monitores

Recurso

Permite reordenar a lista de monitores em tempo real segundo múltiplos critérios:

• Maior Latência Primeiro: Traz para o topo os sites mais lentos ou sob estresse de rede.
• Menor Latência Primeiro: Exibe primeiro os sites mais rápidos.
• Nome (A-Z): Ordenação alfabética pelo nome amigável.
• Offline Primeiro: Destaca imediatamente no topo todos os sites que sofreram queda.

Importação em Lote (.TXT)

Recurso

Permite cadastrar dezenas de sites de uma só vez. Suporta arrastar e soltar arquivos .txt (com uma URL por linha) ou colar diretamente na caixa de texto. O sistema limpa espaços, insere o protocolo https:// automaticamente caso omitido e define frequência padrão de 1 minuto.

Tabela de Códigos de Status HTTP

Código HTTP Significado Estado no Monitor
HTTP 200 OK Requisição bem-sucedida. O servidor respondeu normalmente. ONLINE
HTTP 301/302 Redirecionamento permanente ou temporário de URL. ONLINE
HTTP 403 Forbidden Acesso bloqueado por firewall, WAF ou permissões de pasta. OFFLINE
HTTP 404 Not Found A página ou arquivo na URL informada não foi encontrado. OFFLINE
HTTP 500 Internal Error Erro interno de código PHP, banco de dados ou servidor web. OFFLINE
HTTP 502/503 Service Servidor web (Nginx/Apache) sobrecarregado ou PHP fora do ar. OFFLINE
Erro cURL (0) Timeout (>10s), falha de DNS ou servidor inacessível na rede. OFFLINE

Instalação Local & Implantação em VPS

Execução em Localhost ou Servidor VPS

Deploy

• Docker Compose (Recomendado): Execute docker-compose up -d --build na raiz do projeto e acesse http://localhost:8181.
• Servidor PHP Local: Execute php -S localhost:8181 -t src.
• VPS em Produção: Pode ser hospedado usando Apache/PHP 8 com extensão pdo_sqlite e curl ativas ou via Docker com Proxy Reverso Nginx + SSL Certbot.
